## button

A native button with explicit type and visual emphasis.

Source: [template](../components/button.html) · [contract](../components/button.json)

| Prop | Type | Default | Allowed values |
| --- | --- | --- | --- |
| `type` | string | `"button"` | `button`, `submit`, `reset` |
| `variant` | string | `"primary"` | `primary`, `secondary`, `ghost`, `danger` |
| `size` | string | `"md"` | `sm`, `md`, `lg` |
| `disabled` | boolean | `false` | — |
| `name` | string or null | omitted | — |
| `value` | string or null | omitted | — |

Slots:

- `default`: required

### Usage

```xml
<main xmlns:t="urn:cococo:dataxml" class="portal-theme portal-example">
  <div style="display:flex;gap:1rem;flex-wrap:wrap">
    <portal-component name="button">Continue</portal-component>
    <portal-component name="button">
      <portal-prop name="variant" value="secondary"/>
      Save draft
    </portal-component>
  </div>

```

### Accessibility and limits

Uses a real button. Choose type="submit" inside a form; the default button never submits accidentally. Disabled buttons remain native disabled controls. Visible text supplies the accessible name.

IDs must be unique in the document.

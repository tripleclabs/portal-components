# Component reference

Generated from catalogue.json, the component files (components/<name>.portal) and executable example source. Do not edit this file directly. Library 0.4.0, contract 1.

Usage snippets go inside a page template. In a `.portal` file the `ui:` and `t:` prefixes are implicit; a plain `.html` page declares `xmlns:ui="urn:cococo:ui"` and `xmlns:t="urn:cococo:dataxml"` on its root.

### Usage

```xml

  <ui:button>Continue</ui:button>
```

    Authentication

    Send your secret key as a bearer token and keep it on your server. Test keys never print or charge.

    curl https://print.example/v1/orders \ -H "Authorization: Bearer $PAPER_AND_FORM_KEY"

    Endpoints

    reference string Yes The order reference, for example PF-1042. estimate string Yes The estimate to accept. Prices are fixed when it was issued. deliveryNote string or null No Instructions for the courier.

    Examples

    curl https://print.example/v1/orders/PF-1042 \ -H "Authorization: Bearer $PAPER_AND_FORM_KEY" const response = await fetch("https://print.example/v1/orders/PF-1042", { headers: { Authorization: `Bearer ${process.env.PAPER_AND_FORM_KEY}` }, }); const order = await response.json(); { "reference": "PF-1042", "status": "printing", "total": "58.80", "currency": "GBP" }

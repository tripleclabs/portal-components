# Provenance

This repository is a **generated distribution mirror**. Authoritative source is maintained in platform at `packages/portal-components`. Make changes upstream; the library, docs and production-rendered previews are exported here. Public CI needs Node only and never depends on platform. Platform runtime consumes a pinned public commit, not the authoring directory.

The templates, contracts, CSS, documentation and build scripts in this repository were created for Portal Components and are distributed under the MIT license in LICENSE. They are not copied from shadcn/ui or daisyUI; those projects inspired the ownable-source and theme-token product model.

The examples in rendered/ are generated from this repository's component and example source by the platform's production Swift PortalSiteKit compiler/renderer. rendered/manifest.json records input and output hashes and a renderer source fingerprint. The platform compiler is not included in this repository. Public builds validate the recorded files and use those pre-rendered examples; platform integration checks regenerate them with the actual compiler.

Playwright and axe-core are development-only dependencies, pinned in pnpm-lock.yaml. Their source is not bundled into the component library or the deployed component example pages. Browser tests load axe-core only while auditing local generated examples.

The static documentation site uses system fonts and local assets. It contains no external analytics, customer data, credentials or required third-party hosted resources.

## Public distribution boundary

The production compiler and server implementation are not distributed here. Rendered HTML is static synthetic output; its manifest contains relative library paths, hashes and version metadata, not embedded server source. Public Node scripts build documentation and run tests only. A clean repository export excludes node_modules, generated site output, Git metadata and build caches; it includes only the explicitly reviewed public library, documentation, examples, render artifacts and tooling.

## Documentation branding

The docs shell uses official CoCoCo artwork and self-hosted Sofia Sans fonts. See [brand asset provenance and license scope](brand/NOTICE.md). Font binaries are presentation assets, not server code; only the reviewed brand folder is included in the public export.

The docs build pre-highlights XML/DataXML, CSS and JSON with Highlight.js. The same escaped renderer highlights live theme exports. Its BSD license is preserved in [third-party credits](docs/third-party.md); the browser bundle contains only public dependencies and docs code.

## Bundled icons

`styles/icons.css` is generated by `pnpm run icons` from the pinned `lucide-static` devDependency: 40 Lucide icons (ISC; a few derive from Feather, MIT) encoded as CSS masks. The full notices are in `icons/NOTICE.md`, which ships with the package and the Portal host; the stylesheet keeps a `/*!` pointer to it that survives the host's minified bundle.

Orders API

Place, track and reorder print from your own systems. Every request is authenticated with a secret key and returns JSON.

OpenAPI document

Authentication

Send your secret key as a bearer token and keep it on your server. Test keys never print or charge.

ShellCopied
curl https://print.example/v1/orders \
  -H "Authorization: Bearer $PAPER_AND_FORM_KEY"

Endpoints

GET/v1/orders/{reference}

Retrieve one order with its line items and production status.

Path parameters
NameTypeRequiredDescription
referencestringYesThe order reference, for example PF-1042.

POST/v1/orders

Place an order from an accepted estimate.

Body fields
NameTypeRequiredDescription
estimatestringYesThe estimate to accept. Prices are fixed when it was issued.
deliveryNotestring or nullNoInstructions for the courier.

DELETE/v1/orders/{reference}

Cancel an order before its proof is approved.
